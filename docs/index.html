Splicedock

Self-hosted MCP gateway

Aggregate upstream MCP servers, REST APIs, and CLI tools behind a single Model Context Protocol endpoint.

One endpoint. Every tool. Your servers.

What It Does

∞

Aggregate Everything

Connect MCP servers, REST APIs, and CLI tools. Splicedock discovers, registers, and exposes them all through a single unified interface.

●

One Endpoint

Clients connect once to Splicedock and gain access to every tool. No more hunting for individual API docs or managing separate credentials.

🔒

Self-Hosted

Run Splicedock on your own infrastructure. Your tools stay on your servers. No cloud dependency, full control over data and access.

Install

Get Splicedock running locally in seconds.

1

Clone the repository

git clone https://github.com/kamilrybacki/splice-dock.git splicedock
cd splicedock
2

Run the server

npm run dev

Start the dev server with an admin token of your choice; MCP is served on localhost:8788.

3

Verify installation

curl http://localhost:8788/api/v1/health

Returns {"status": "ok"} if Splicedock is running correctly.
